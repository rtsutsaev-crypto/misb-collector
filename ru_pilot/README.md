# Пилот: что открывается с российского сервера

Цель — за один день и около 40 ₽ выяснить, сколько закрытых для облака Claude площадок читается из России, и есть ли на них
закупки обучения. Пока это оценка (по грубому счёту +5–15 % лидов), пилот заменяет её измерением. Сервер нужен только на время
пилота: постоянный сервер арендуют, если пилот покажет, что открылось достаточно.

В `urls.json` 93 адреса, которые облако не смогло прочитать: нет ответа (сброс соединения), 403 и 503, экран «проверка
безопасности», переадресация без конца, запрет в `robots.txt`. Список собран скриптом `build_urls.py` из реестра источников
(43 адреса), проверки каталога (44) и документов `sources` (27). Ключей в нём нет.

## 1. Заказ сервера

Timeweb Cloud, тариф Cloud-50 (1 ядро, 2 ГБ, 30 ГБ), https://timeweb.cloud/services/vds-vps

- Локация Москва, Ubuntu 24.04, почасовая оплата, публичный IPv4.
- Вход по SSH-ключу, а не по паролю. Пароль администратора из письма не нужен, если при заказе указан ваш ключ.
- Без панелей управления, без дополнительных пакетов из каталога Timeweb.
- Подойдёт и другой российский хостинг с российским IP: важно, чтобы адрес был из России, а не из облака известного зарубежного провайдера.

## 2. Что поставить на сервер

**Самый простой путь, без архива.** Откройте `paste_to_server.txt`, скопируйте весь текст и вставьте его в консоль сервера (веб-консоль
в панели Timeweb или `ssh root@<адрес>`), нажмите Enter. Блок сам поставит python3 (если его нет), соберёт скрипт со списком адресов
и запустит проверку в папке `~/pilot`. В конце в консоли будет «ИТОГ»: скопируйте его или сделайте снимок экрана и пришлите. Блок собирается
командой `python3 make_one.py`.

Путь с архивом (если вставка в консоль не подошла):

Репозиторий закрытый, поэтому переносим один файл `ru_pilot.zip` (в нём всё нужное, 20 КБ):
```
scp ru_pilot.zip root@<адрес сервера>:~
ssh root@<адрес сервера>
apt-get update && apt-get install -y python3 unzip
unzip ru_pilot.zip && cd ru_pilot
```
Второй путь, если у вас есть доступ к репозиторию с сервера: `git clone` и `git checkout claude/create-trigger-task-no-schedule-esebbw`.

Ключи ГосПлана, TenderGuru, Checko и других на сервер **не копируются**: скрипт ходит только на публичные страницы.

## 3. Запуск

```
python3 probe_ru.py                 # все 93 адреса, около 8–12 минут
python3 probe_ru.py --limit 10      # быстрая проба
python3 probe_ru.py --only tektorg  # адреса, в названии или ссылке которых есть слово
```

Правила скрипта (честный сбор, без обхода):
- перед каждой страницей читает `robots.txt` сайта; запрещённое не открывается;
- один запрос на страницу, пауза 2 секунды, представляется как `misb-collector-pilot/1.0`;
- проверка TLS включена; капчу, «проверку браузера», 403 и 429 не обходит, а записывает как результат;
- без входа в аккаунты, без форм, без ключей.

Результаты на каждый адрес:
- `list` — страница открылась и в ней виден список закупок (слов о закупках не меньше 5 и дат не меньше 3);
- `shell` — страница открылась, но списка нет: его рисует скрипт страницы;
- `gate` — экран-заслон (капча и т. п.), `blocked` — 401, 403, 404, 429, 451 или 5xx, `error` — нет ответа,
  `redirect` — переадресация без результата, `robots` — раздел закрыт в `robots.txt`.

Для «оболочек» второй этап одним блоком: `paste_browser.txt` (вставить в консоль сервера после первого прогона в той же папке `~/pilot`; ставит node, Playwright 1.49.1 и Chromium, читает только страницы класса `shell` из `result.json`, пишет `result_browser.json` и `report_browser.md`).
Вручную то же самое (по желанию): `python3 probe_ru.py --only <часть> --browser`. Ему нужны node и Playwright:
```
sudo apt-get install -y nodejs npm
npm install playwright && npx playwright install --with-deps chromium
PLAYWRIGHT_MODULE=$(pwd)/node_modules/playwright python3 probe_ru.py --browser
```
Браузер читает страницу один раз, как обычный посетитель, и заслон тоже не обходит.

## 4. Что прислать обратно

Файлы `result.json` и `report.md` из папки `ru_pilot`. В отчёте: сколько адресов открылось, для каких список виден, сколько строк
про обучение на первых страницах, таблица «облако — российский сервер» по каждой площадке. Сравнение с базой (что из этого уже
есть в лидах, что новое) делаю я. Отправить можно как файлы в чат или командой `cat report.md`.

## 5. Решение после пилота

| Итог пилота | Что делать |
| --- | --- |
| открылось 25 адресов и больше, на них видны закупки обучения | арендовать сервер постоянно и перенести на него сбор этих площадок (отдельный адаптер по каждой) |
| открылось 10–25, списки в основном пустые оболочки | подключить браузерный этап только для лучших площадок, сервер не держать |
| открылось меньше 10 или всё то же: сброс, 403, заслон | сервер не нужен: закрытость связана не с адресом облака, а с защитой самих площадок |

## 6. Как закончить

Удалить сервер в панели Timeweb сразу после отправки результатов (почасовая оплата, за сутки около 35–45 ₽). Ключей и данных на
нём нет, других действий не требуется.
