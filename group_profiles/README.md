# Профили закупок групп: головные, дочки, внучки

`profile_groups.py` — первый полный проход профилей групп для вкладки «Корпорации». Запускается из
сеанса Claude Code по выгрузке базы сайта (ArtifactData `get`/`list` с `out_dir`); ключ ГосПлана — только
в переменной окружения `GOSPLAN_KEY`, в файлы и базу не пишется.

```
python3 profile_groups.py targets W        # состав групп -> W/out/group-targets.json
GOSPLAN_KEY=... python3 profile_groups.py fetch W --workers 12 --pause 0.5   # W/raw/<ИНН>-223|44.json, можно продолжать
python3 profile_groups.py build W          # W/out/profiles/<ИНН головной>.json, W/out/leads.json, W/out/summary.json
```

**Состав группы.** Головная — из `meta/holdings` (365 групп с ИНН). Дочки, внучки, правнучки — из
`orgdir/hier-*` (привязка к группе реестра по `hierGroup`), затем проверенные и заявленные связи из
`orgdir/index-*` (кроме исторических), компании групп из `orgdir/orgs-*` и привязки по ЕГРЮЛ из
`ownership`. ИНН берётся один раз — на самом близком к головной уровне. Итог 28.09.2026: 1 569 компаний
(головных 365, дочек 780, внучек 148, правнучек 39, прочих компаний групп 236).

**Запросы.** `/fz223/purchases` у каждой компании, `/fz44/purchases` у головной и учреждений; параметры
`customer=<ИНН>`, `published_forpast=12m`, `limit=100`, `sort=published_at_desc`. Лимит ключа — 10 запросов
в секунду и 12 000 в час (заголовки `x-ratelimit-*`); 12 потоков с паузой 0,5 с дают 2–5 запросов в секунду.

**Отбор по темам МИСБ.** `config/dictionary`: закупка засчитывается, если в названии есть форма обучения
(форматы словаря и общие слова — обучение, повышение квалификации, семинар, тренинг, конференция…) или код
ОКПД2 строки из списка словаря, и нет исключений. Тема без формы («экология», «охрана труда») не
засчитывается: иначе в профиль попадают инженерные изыскания и ремонт. Слабые формы («тестирование»,
«аттестация», «информационно-консультационные услуги») засчитываются только вместе с темой. Слова до
3 букв (ЛИН, ДПО) — только целым словом, длинные — по основе, срезанной не короче 5 букв («продажи» не
совпадает с «продукцией»).

**Документ** `groupprofiles/<ИНН головной>`: `group, inn, checkedAt, scope: "группа", companies,
withPurchases, total, total223, total44, relevant, platforms, examples[≤8], members[], note, via`.
Дальше профили обновляет основное задание сбора (этап `group-profile`, см. `routine/CARRYOVER.md`, п. 5).
