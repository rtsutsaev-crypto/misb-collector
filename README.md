# misb-collector

Сбор закупок обучения для «Монитора-консолидатора МИСБ» (артефакт на claude.ai). Основное задание сбора —
Routine без расписания, запускается кнопкой «Обновить» на сайте; данные хранятся в общей базе сайта.

| Каталог | Назначение |
| --- | --- |
| `site/monitor.html` | код сайта (тело артефакта) |
| `collector/` | скрипты сбора, которые запускает Routine по кнопке «Обновить» (клон на закреплённом коммите) |
| `routine/CARRYOVER.md` | правки, которые переносятся в каждую новую версию текста задания |
| `gosplan_deep/` | глубина по ЕИС через ГосПлан, планы закупок 44-ФЗ и 223-ФЗ, записи плана для соседних рынков |
| `tenderguru/`, `b2b_center/`, `energybase/`, `import_mtrf/` | источники и импорты |
| `egrul/`, `group_profiles/` | владельцы и профили закупок групп |
| `sources_probe/` | проверка адресов из облака |
| `source_registry/` | реестр 100 источников: сопоставление, проверка, документы `srcreg` |
| `import_corp_xlsx/` | книга компаний и отраслей |
| `browser_lists/` | чтение сайтов со списком, который строит скрипт (headless Chromium, robots.txt, без обхода защиты) |
| `ru_pilot/` | суточный пилот на российском сервере: что открывается из России из 93 закрытых для облака адресов |
| `standalone/` | отдельная версия без Claude: свой сервер, база SQLite, сбор моделью через OpenRouter (см. `standalone/README.md`, правила для агентов — `AGENTS.md`) |

Ключи API (ГосПлан, TenderGuru, Чекко) хранятся только в тексте задания; в репозиторий, базу сайта и отчёты
они не попадают.
