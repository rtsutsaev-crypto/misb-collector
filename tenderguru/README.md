# TenderGuru: расширенные запросы и выборка по площадкам

Перенос поисковых запросов «Монитора тендеров РФ» в наш сбор (28.09.2026). Сами запросы лежат в
`queries.json`, а в работе они живут в `config/sources-plan` базы как два источника типа `api`:

| Источник плана | Что | Порция за запуск |
|---|---|---|
| `tenderguru-more` | 37 слов: электронный курс, мини MBA, ДПО, практикум, стажировка, СДО, LMS, охрана труда, промышленная безопасность, бухгалтерские и закупочные семинары, подбор спикеров и др. | 12 запросов |
| `tenderguru-etp` | 52 запроса с фильтром площадки: РТС-тендер (e76), Сбербанк-АСТ (e1, e26, e47), Росэлторг (e2, e31), Фабрикант (e12), ЭТП ГПБ (e46) × 8 тем; OTC (e36), ЗаказРФ (e3), РАД (e37), SberB2B (e120) × 3 темы | 13 запросов |

**Ротация.** Оба источника (и `energybase-cos`) читаются порциями по кругу: поле `batch` у источника,
курсор — `meta/rotation`, `cursors.<key>`. За несколько запусков список проходится целиком, а один запуск
не растёт.

**Ограничения тарифа** (проверено 28.09.2026): API отдаёт 10 самых новых карточек на запрос, вторая страница —
«access denied», заказчик, площадка и официальный номер скрыты. Поэтому у лидов `customer` пустой, а площадка —
из фильтра запроса (поле `platform`, `source` = `tenderguru:etp`). Оператор «|» объединяет только
одиночные слова: с фразой или дефисом выборка занижается.

**Коды площадок.** Проверены по карточкам с известной площадкой (`queries.json` → `platforms`). Не подтверждены
и не включены: e19, e34, e58, e71, e69, e18, e92. `search.php` у TenderGuru закрыт в robots.txt, поэтому берётся
платный API с теми же фильтрами, а не страница поиска.

**Первый проход** (`tg_run.py`, из сеанса Claude): 89 запросов, 874 строки; не по теме 432, давно закрытых 91,
уже в базе 226; после исключений словаря новых 119 (36 с открытым приёмом) →
`leadsets/run-20260928-2100-tenderguru-more` (78) и `…-tenderguru-etp` (41).

## Запуск вручную

```
TENDERGURU_KEY=… python3 tg_run.py W [--part extra|etp|all] [--start N] [--count N] [--pause 3]
```

`W/db/config/dictionary.json` и `W/db/leadsets/*.json` — выгрузка базы (ArtifactData с `out_dir`). Результат:
`W/out/tenderguru-<part>.json` (готовый документ leadsets) и `-stat.json`. Ключ берётся только из переменной
окружения; в репозиторий и базу ключи не кладутся.
