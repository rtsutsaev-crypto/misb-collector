# Ручной сбор закупок B2B-Center

Файл `b2b_center_manual_sync.py` — самостоятельный прототип на Python 3.10+ без внешних библиотек. Он читает вкладку **«Все» собственной публичной площадки** `https://www.b2b-center.ru/market/?show=all`, сохраняет закупки в SQLite и запускается только по команде или нажатию кнопки. Это позволяет увидеть и процедуры, закрывшиеся между ручными запусками. Продажи пропускаются, но учитываются при переходе к следующей странице. Он не обращается к широкому агрегатору `/search/`, где есть закупки других площадок.

## Запуск прототипа

```bash
python3 b2b_center_manual_sync.py serve --db b2b_center.sqlite3
```

Откройте `http://127.0.0.1:8765/` и нажмите «Проверить новые закупки». Возможен ручной запуск без страницы:

```bash
python3 b2b_center_manual_sync.py scan --db b2b_center.sqlite3
python3 b2b_center_manual_sync.py status --db b2b_center.sqlite3
```

**Прежде чем использовать результат в рабочем мониторе:** проверьте парсер на живой странице B2B-Center из среды, где работает ваш сайт. Структура живой HTML-строки была просмотрена в браузере, но сквозной запуск сетевого Python-скрипта здесь не проведён; тесты используют HTML-фикстуры с той же структурой. При изменении вёрстки он должен завершиться ошибкой и сохранить старую контрольную отметку. Если `robots.txt` запрещает этот путь, сбор останавливается; тогда запрашивайте официальный API/разрешение.

> Прочитай `README_B2B_CENTER_CLAUDE_CODE.md` и `b2b_center_manual_sync.py`. Встрой ручной импорт публичных закупок B2B-Center в существующий сайт. Сначала изучи стек, схему БД, авторизацию, существующие адаптеры закупок и UI; используй их, не создавая отдельный боевой сайт или параллельную основную базу. Прототип можно перенести на язык проекта либо запускать на сервере как отдельный модуль. Добавь видимую кнопку «Проверить B2B-Center» в текущий монитор. Только нажатие авторизованного пользователя запускает серверную задачу. Никаких cron, timers, фонового расписания или автоматического запуска при открытии страницы. Периодический запрос **только статуса уже запущенной задачи** допустим, пока пользователь смотрит страницу.
>
> По нажатию создай задачу и немедленно верни её ID; показывай прогресс (страницы, просмотренные карточки, новые, обновлённые, ошибка). Защити endpoint авторизацией и CSRF, исключи параллельный запуск. Не запускай длинный импорт внутри одного HTTP request. Сохраняй контрольную отметку времени **начала последнего полностью успешного сканирования** лишь после завершения всех страниц и повторной проверки активных карточек. При ошибке отметку не сдвигай. Новый запуск должен повторить период от предыдущего успеха с двухдневным перекрытием. Первый запуск охватывает 14 дней; историческую глубину можно менять явным параметром в UI. Если предел страниц/время/изменение HTML/ограничение сайта не позволяют дойти до старой отметки, покажи «охват неполный» и сохрани старую отметку.
>
> Загружай со вкладки **«Все»** `/market/?show=all` все публикации до контрольной отметки, листая по дате публикации, в том числе уже закрывшиеся. Не смешивай закупки с объявлениями о продаже. По каждому номеру закупки открой карточку, сохрани `source=b2b-center`, `external_id`, исходный URL, название, организатора, заказчика (если доступен), дату публикации, срок подачи, дату редактирования, статус и дату проверки. Повторно открывай ранее сохранённые активные карточки, чтобы увидеть перенос срока/изменения. Не отсекай закупки по ключевым словам при сборе: после загрузки используй существующий фильтр института (обучение, ДПО, электронные курсы, вебинары, тренинги, стратсессии, мероприятия, конференции), сохраняя и неоценённые записи. Дедупликация: ключ `(source, external_id)` и отдельная дедупликация с ЕИС/другими площадками там, где это тот же конкурс. Сопоставляй организатора/заказчика по ИНН с существующей базой групп и дочерних обществ, если ИНН действительно есть в карточке; не угадывай ИНН по имени.
>
> Прежде чем считать задачу готовой, проверь HTML живой публичной страницы и карточки, количество извлечённых строк, корректность двух дат и переход на следующую страницу. Добавь тест с несколькими страницами и сбоем посередине, доказывающий, что контрольная отметка не сдвигается и следующий ручной запуск догоняет пропущенное. Проверь изменение срока заявки и отсутствие повторов. Уважай ограничения доступа площадки, не обходи CAPTCHA/403/авторизацию. Если парсинг страницы невозможен, выведи понятную ошибку, а не пустой «успешный» результат.
>
> Покажи итог: изменённые файлы, как запустить, результат живого smoke-test, число импортированных процедур, какие поля недоступны и что остаётся для официального API. Не утверждай, что охвачены закрытые закупки или корпоративные площадки, пока это не подтверждено проверкой.

## Что уже делает прототип

- Сохраняет всю считанную выдачу без удаления процедур, которые не попали в словарь тем. `matched_terms` — только пометка по заголовку.
- Останавливается по времени предыдущего **успешного** запуска с перекрытием два дня; не ограничивается последними двумя днями, если пользователь давно не нажимал кнопку.
- При сбое не сдвигает контрольную отметку и явно сохраняет ошибку.
- Проверяет запрет в `robots.txt`, повторяет временные ошибки с паузой, ограничивает размер страницы, обнаруживает повторяющуюся пагинацию и изменение порядка сортировки.
- Обновляет карточки ранее найденных открытых процедур и извлекает изменённый срок при наличии поля на странице.
- Слушает только `127.0.0.1`. Демонстрационный HTTP endpoint **не имеет авторизации** и не должен публиковаться в интернет как есть.

## Границы решения

Публичный список не гарантирует видимость приглашённых и закрытых процедур. В просмотренной публичной карточке документация организатора доступна только зарегистрированным пользователям; поэтому этот прототип собирает публичные сведения, а не файлы закупки. Официальный API B2B-Center существует, но документация и тарифы доступны через кабинет; наличие метода полного чтения новых процедур для поставщика требуется отдельно подтвердить у площадки. RSS с проверенным публичным URL для списка закупок не найден. На стадии интеграции API лучше использовать как замену источника данных при сохранении того же ручного запуска и той же контрольной отметки.
