Срез исследования: 01.10.2026. Часовой пояс: Europe/Moscow.

НАЧНИТЕ ЗДЕСЬ
V4 расширяет пакет MISB_growth_v3_Claude_Code.zip. Исходные данные v3 сохранены. Не заменяйте существующее приложение пользователя и не удаляйте старые записи. Импортируйте добавления по ID, сохраняя ручную работу менеджеров.
Цель — меньше пропущенных потребностей. Ложные срабатывания, дубли, недатированное и закрытые источники сохраняются.

ФАКТИЧЕСКИЙ РЕЗУЛЬТАТ
- Выполнен аудит структуры покрытия 136 источников и 239 адресов. Это проверка маршрутов и пробелов реестра, а не новое чтение всей истории всех источников.
- 259 новых групп кандидатов для исследования. Ещё 47 слабых/смежных групп сохранены отдельно. Каталоги, альтернативные домены и сообщества могут пересекаться. Числа не означают независимые компании или источники с доказанными свежими заказами.
- 441 запись происхождения находок; 40 повторных находок относятся к уже известным источникам.
- 324 новых поисковых конструкции сверх словаря v3: разговорный спрос, планирование, замена провайдера, электронные курсы, приглашения партнёров; варианты RU/EN/KZ/BY.
- Код Python для 17 настроек источников и четырёх семейств HTML-разбора: Telegram, списки, статьи, страницы партнёрства.
- Проверены 18 обращений через веб-ридер: 14 страниц дали содержимое, 3 ошибки, 1 CAPTCHA. Реальные тексты этих 14 страниц прогнаны через импорт ридера. Целые ленты не выданы за отдельные лиды.
- Прямой HTTP-доступ из среды разработки ограничен: успешных нативных HTTP-проверок источников нет. HTML-парсеры проверены на контролируемых примерах, а не на живом DOM этих сайтов. Настройки требуют проверки в среде приложения.
- 26 тестов кода пройдены. Проверены связи ответов Telegram, ревизии и сохранение заметок, неизвестные даты, пагинация, ошибки доступа, извлечение PDF/DOCX/XLSX, английский OCR.
- Модель OCR русского языка в этой среде отсутствует. Английский пример дал опечатку в слове TRAINING; OCR нельзя считать точной расшифровкой. Перед рабочим применением установить rus и проверить русские брифы.
- Автоматическое расписание, платные API, переписка и пилот не запущены. Новых подтверждённых покупателем лидов: 0. Рост 10x ещё не измерен.

КОД: КАК ЗАПУСКАТЬ
Нужен Python 3.11+. Базовый модуль использует стандартную библиотеку. Для PDF нужен pdftotext; для картинок — tesseract и нужные языковые модели. Для теста OCR нужен pdftoppm.
Из папки v4:
python test_hr_scan.py
python hr_scan.py --help
python hr_scan.py --db stage.sqlite --as-of 2026-10-01 fetch --config collector_config.jsonl --source FD-S001 --max-pages 2
python hr_scan.py --db stage.sqlite telegram-export --file permitted_export.json --source FD-S009
python hr_scan.py --db stage.sqlite attachment --file brief.pdf --source FD-S001 --parent EXISTING_DOCUMENT_ID
python hr_scan.py --db stage.sqlite attachment --file screenshot.png --source FD-S001 --parent EXISTING_DOCUMENT_ID --ocr-lang rus+eng
python hr_scan.py --db stage.sqlite audit-sample --out audit.csv --per-source 10
python hr_scan.py --db stage.sqlite export --out stage_export

HTTP-команда читает только явно разрешённые HTTPS-хосты, проверяет robots, сохраняет ошибки. Если robots недоступен, не объявляет сайт прочитанным. Список сначала даёт item_link; дочерние карточки остаются маршрутами detail_to_fetch. Не считать ссылки готовыми запросами. Переходы к следующей странице выполняются лишь по наблюдаемым ссылкам; лимит страниц отражён в результате. Полный обход истории и возобновление всей очереди после перезапуска необходимо подключить в существующем приложении.
SQLite — промежуточное хранилище документов, ревизий, маршрутов, запусков и заметок. Это не миграция CRM и не автоматическое создание подтверждённых need_id.

ВЕБ-РИДЕР И АВТОРИЗОВАННЫЕ ЭКСПОРТЫ
Команда reader принимает JSON-массив объектов {url, retrieved_at, text}. text — реально полученное представление страницы с исходным URL; можно использовать текст вида L0: ... из ридера. Подключение ридера предоставляется средой Claude/существующим приложением и в пакет не встроено.
python hr_scan.py --db stage.sqlite reader --snapshots received_pages.json --config collector_config.jsonl
Исследовательские полные снимки не включены в архив; сохранены ссылки, хэши и результаты обработки. Для повторения живой проверки получите страницы заново.
Telegram export импортирует ответы, автора, дату и путь вложения. Если публичной ссылки нет, создаётся явно локальный telegram-export:// идентификатор. Он не выдаётся за открываемый URL Telegram.
Комментарии публичных сайтов и автоматическая загрузка вложений ещё требуют адаптеров конкретных сайтов. Локальная обработка разрешённых файлов уже реализована.

ПОСЛЕДОВАТЕЛЬНОСТЬ ИНТЕГРАЦИИ
1. Прочитать существующую схему приложения. Сохранить исходные FD-S/FD-O/FD-X/FD-N/FD-B/FD-E и ручные поля. V4-S/V4-D — кандидаты и доказательства, а не готовые лиды.
2. Импортировать данные v4 идемпотентно. До создания нового источника показать возможные совпадения со старым; не удалять происхождение.
3. Прогнать настройки HTTP на целевом сервере. Проверить реальные HTML-селекторы, ссылки карточек, даты и пагинацию. При ошибках использовать разрешённые экспорты или ридер.
4. Подключить существующую очередь detail_to_fetch, комментариев и вложений. Не переходить от пустой страницы к выводу «спроса нет».
5. Сохранять сырой документ локально, ревизии и короткие доказательства. Сначала дешёвое извлечение, затем LLM только для новых или изменённых материалов. Словарь не является жёстким фильтром.
6. Роли автора, заказчика и администратора различать. Общий HR-контакт не считать владельцем конкретного запроса. Ставить buyer_confirmed только после ручного подтверждения.
7. Вести last_14_days и days_15_30 по дате публикации; неизвестные, старые открытые и постоянные приглашения не удалять. Для API поиска задавать даты явно; при лимите выдачи дробить окно и сохранять флаг неполноты.
8. Внести расходы всех модулей; только затем оценивать платные индексы. Данный пакет ничего не покупает и не рассылает.
9. Перед пилотом провести независимую ручную выборку всех типов материалов, включая unmatched. На листе «Пропуски v4» есть реальные проверенные страницы для ручной разметки. Ленты сначала разделить на сообщения; счётчик страниц не является полнотой обнаружения лидов.
