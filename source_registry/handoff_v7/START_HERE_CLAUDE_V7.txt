ПОРЯДОК РАБОТЫ
1. Прочитать SOURCE_OPERATING_GUIDE.txt и policy.json. Посмотреть audit/metrics.json.
2. Начать с data/priority_reviews.jsonl и data/commercial_examples.jsonl; проверить актуальность приема, оплату, тему, договор с институтом и ответственного. Никому не писать автоматически.
3. Вести реестр data/source_registry.jsonl вместе с прежними маршрутами. data/expansion_candidates.jsonl — 417 новых кандидатов; исходная поисковая доказательная база — discovery_provenance.jsonl. Не повышать search_result_only до подтвержденного спроса.
4. data/observed_routes.jsonl содержит 20 наблюденных адресов. data/surface_tasks.jsonl содержит 2634 задачи для 439 маршрутов: лента/запросы, комментарии, вложения, партнерство, авторы, первоисточник. Пустой exact_urls — задача, не готовый коннектор. Некоторые поверхности могут оказаться неприменимы.
5. Выполнить локальную валидацию: python code/source_ops.py validate. Подготовить ограниченный план: python code/source_ops.py plan --limit 20 --out plan.jsonl.
6. Только после проверки конкретных адресов запустить read-only сбор: python code/source_ops.py scan --source SOURCE_ID --db pilot.sqlite --as-of YYYY-MM-DD --max-pages 2. Для пакетного запуска передать --plan plan.jsonl. Сам пакет не назначает расписание и не запускает сеть при открытии.
7. Для разрешенных экспортов Telegram, OCR/PDF и снимков web-reader использовать v6/v5/legacy/F02/claude_package/v4/hr_scan.py. Формат и команды — SOURCE_OPERATING_GUIDE.txt. Не пытаться получать закрытые чаты без разрешенного доступа.
8. Сначала сохранять все наблюдения; затем размечать сигнал. Дубли связывать в группу, сохранять автора, репост и время. Вакансия, реклама провайдера, спонсорство и конференция не становятся закупкой обучения автоматически.
9. Заполнять source_performance.jsonl и feedback.jsonl. Неизвестное — null, не 0. Измерять новые уникальные подходящие возможности и трудозатраты; общий балл не должен скрывать старую дату или отсутствие покупателя.
10. Расширять сеть по всем направлениям из research_targets.jsonl. Недобор по направлениям указан явно. Сохранять старую базу и различать «новый адрес» и «новая организация».
