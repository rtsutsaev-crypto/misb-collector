# Монитор МИСБ — отдельная версия без Claude

Своя, независимая копия «Монитора-консолидатора МИСБ»: тот же сайт (`site/monitor.html`), те же скрипты и инструкция сбора
(`collector/`), но всё работает на вашем сервере. Данные лежат в своей базе, сбор ведёт модель через OpenRouter, ключи свои.
С версией на Claude ничего не связано: после переноса снимка данных каждая версия живёт сама по себе.

```
браузер ──HTTPS──> Caddy ──> misb.server (сайт + API базы, пароль)
                                │  кнопка «Обновить» / таймер 09:00 МСК
                                ▼
                            misb.agent ──> OpenRouter (модель ведёт сбор по collector/INSTRUCTIONS.md)
                                │  инструменты: Bash (скрипты collector/), WebFetch, WebSearch, ArtifactData (база)
                                ▼
                            SQLite /var/lib/misb/misb.sqlite3
```

| Файл | Что делает |
|---|---|
| `misb/store.py` | база документов «коллекция/документ» с версиями на SQLite (та же модель, что у базы артефакта Claude) |
| `misb/server.py` | отдаёт сайт и API `/api/doc`, `/api/col`, `/api/revs`, `/api/refresh`; вход по паролю (HTTP Basic) |
| `web/claude-shim.js` | прослойка: сайт написан для `window.claude`, здесь те же вызовы идут на свой сервер |
| `misb/agent.py` | сбор: цикл модели с инструментами, лимиты расходов и ходов, один сбор за раз |
| `misb/tools.py` | инструменты агента: Bash, WebFetch, WebSearch, ArtifactData, ToolSearch |
| `misb/relay.py` | локальный «релей»: сервер в России читает сайты, закрытые для облака, напрямую |
| `misb/snapshot.py` | загрузка и выгрузка снимка данных (папка `<коллекция>/<документ>.json`) |
| `deploy/` | `install.sh`, службы systemd, таймеры, `Caddyfile`, `env.example`, резервные копии |
| `tests/` | проверка без сети: `python3 -m unittest discover -s tests` из этой папки |

## Что нужно

1. **Сервер в России**: VPS с 2 ГБ памяти, 1–2 ядрами, 20 ГБ диска и Ubuntu 24.04. Подойдёт любой хостинг, ≈300–800 ₽ в месяц.
   Сервер в РФ нужен потому, что часть сайтов закупок не открывается из-за рубежа.
2. **Домен** (желательно): для HTTPS. Подойдёт поддомен своего домена или бесплатный вида `<ip>.sslip.io`.
3. **OpenRouter**: аккаунт, пополненный баланс и ключ (https://openrouter.ai/keys). Модель выбирается ниже.
4. **Свои ключи источников**, каждый на своё имя:
   - ГосПлан (обязателен, на нём основа сбора);
   - DaData (бесплатный тариф);
   - TenderGuru (бесплатный или «Стандарт»);
   - Чекко (по желанию).

   Пустой ключ не ломает сбор: агент пропускает источники с ним (статус skipped, «нет ключа»).
5. **GitHub**: свой форк репозитория `misb-collector`.

## Установка

```bash
# на сервере, от root
git clone https://github.com/<ваш-аккаунт>/misb-collector.git /opt/misb
bash /opt/misb/standalone/deploy/install.sh /root/misb-snapshot.zip   # снимок данных — файл, полученный при передаче
nano /etc/misb/env              # ключи OpenRouter и источников, модель, адрес сайта (пароль сайта уже создан)
systemctl restart misb-server
```

**HTTPS.** Впишите свой домен в `deploy/Caddyfile` и скопируйте файл в `/etc/caddy/Caddyfile`, затем `systemctl reload caddy`.
A-запись домена должна указывать на IP сервера.

**Пробный сбор.** Запустите и смотрите журнал:

```bash
systemctl start misb-collect@full --no-block
tail -f /var/log/misb/run-full.log
```

В журнале видно каждое действие агента и расходы (`$…` каждые 20 ходов и в конце). Первый раз запустите с
`MISB_MAX_USD=3`: так вы узнаете реальную цену запуска на выбранной модели.

**Расписание.** Полный сбор идёт каждый день в 09:00 МСК (`misb-collect-full.timer`, включается установкой). Облегчённые
запуски в 12:28 и 18:28 включаются отдельно и стоят денег:

```bash
systemctl enable --now misb-collect-light.timer
```

**Кнопка «Обновить».** Кнопка на сайте запускает полный ручной сбор. Пока идёт один сбор, второй не стартует: кнопка и
таймер держат общий замок.

## Модель и расходы

Агент ведёт **весь** сбор: читает инструкцию (≈125 КБ), запускает скрипты и пишет в базу. Ему нужны вызов инструментов
(tools), контекст от 200 тыс. токенов и аккуратное следование длинной инструкции. Страницы сайтов (WebFetch) и поиск
читает отдельная, дешёвая модель `OPENROUTER_PAGE_MODEL`.

Цены из каталога OpenRouter на 5 октября 2026 года, $ за 1 млн токенов: вход / вход из кэша / выход.

| Роль | Модель | Цена | Заметка |
|---|---|---|---|
| основная, экономно | `deepseek/deepseek-v4-pro` | 0,21 / 0,017 / 0,42 | дёшево, контекст 1 млн, кэш |
| основная, экономно | `qwen/qwen3.7-plus` | 0,32 / 0,064 / 1,28 | |
| основная, экономно | `openai/gpt-5-mini` | 0,25 / 0,025 / 2,00 | |
| основная, качество выше | `google/gemini-3.5-flash` | 1,50 / 0,15 / 9,00 | |
| основная, качество выше | `anthropic/claude-sonnet-5.5` | 2,00 / 0,20 / 10,00 | ближе всего к поведению версии на Claude |
| страницы и поиск | `qwen/qwen3.7-flash` | 0,03 / 0,006 / 0,13 | |
| страницы и поиск | `google/gemini-2.5-flash-lite` | 0,10 / 0,01 / 0,40 | |

Перед выбором проверьте в каталоге https://openrouter.ai/models актуальную цену и наличие tools: каталог меняется.

**Грубая оценка полного запуска.** Это 300–500 ходов, на каждом в модель уходит 40–80 тыс. токенов (инструкция плюс
сокращаемая история), большая часть — из кэша. Получается:

- экономные модели: ≈1,5–3 $ за запуск, ≈4–8 тыс. ₽ в месяц при одном запуске в день;
- модели качеством выше: ≈8–16 $ за запуск.

Реальную цифру покажет журнал первого запуска. Если дорого:

- оставьте только утренний полный сбор;
- уменьшите `MISB_HISTORY_CHARS` (по умолчанию 160 000 знаков истории);
- поставьте `MISB_WEBSEARCH=off`: источники через поиск будут пропускаться.

**Потолок.** `MISB_MAX_USD` ограничивает один запуск. На 90 % потолка агент получает команду дописать итог и остановиться.
Если не уложился в 25 ходов, сбор останавливается, а в `progress/current` пишется ошибка с причиной.

**Качество.** Слабая модель чаще пропускает шаги и хуже выбирает лоты со страниц. Сверяйте число новых лидов с нормой
(раздел «Приёмка»). Если разрыв большой, попробуйте основную модель сильнее.

## Ключи и безопасность

- Ключи лежат только в `/etc/misb/env` (права 640, группа misb). В git, базу и журналы они не попадают.
- Модель ключей не видит: в командах она пишет `"$GOSPLAN_KEY"`, а подстановку делают Bash (окружение) и WebFetch (замена
  в адресе). Значения ключей в выводах инструментов заменяются на имена переменных.
- Сайт закрыт паролем `MISB_USER` / `MISB_PASSWORD` и слушает только 127.0.0.1. Наружу его отдаёт Caddy по HTTPS.
- Правила сбора те же, что в инструкции:
  - капчи, проверки «подождите», страницы входа и robots.txt не обходятся;
  - рассылок нет;
  - платные тарифы — только решение владельца.

## Ежедневная работа

| Что | Как |
|---|---|
| журналы | `/var/log/misb/run-full.log`, `run-light.log`, `run-last.log` (кнопка), `journalctl -u misb-server` |
| рабочие папки сборов | `/var/lib/misb/work/run-…` (хранятся 14 последних) |
| резервная копия базы | каждую ночь в `/var/lib/misb/backup` (14 дней); восстановление: остановить `misb-server`, распаковать `.gz` поверх `MISB_DB`, запустить |
| выгрузка всех данных | `cd /opt/misb/standalone && python3 -m misb.snapshot export /root/export --db /var/lib/misb/misb.sqlite3` |
| обновление кода | `cd /opt/misb && git pull && systemctl restart misb-server` (сбор подхватит новый код при следующем запуске) |

## Приёмка (первая неделя)

1. Неделю обе версии работают параллельно.
2. Каждый день сравнивайте число новых лидов полного сбора. Норма в будни — 61–73; в субботу и воскресенье закупок мало.
3. Если разрыв больше 30 %, разберите по источникам: таблица источников на сайте и `meta/source-report`.
   Типичные причины:
   - нет ключа;
   - слабая модель на источниках `pages`;
   - выключен поиск.
4. В конце недели решите, какую модель оставить и нужны ли облегчённые запуски.

## Неполадки

| Признак | Что делать |
|---|---|
| сайт не открывается | `systemctl status misb-server`, `journalctl -u misb-server -n 50`; проверить Caddy и DNS |
| кнопка пишет «сбор уже идёт» | идёт сбор по таймеру или прошлый; `curl -u misb:… https://<домен>/api/run` |
| сбор встал с ошибкой модели | `run-*.log`: 401 — ключ OpenRouter, 402 — баланс, 404 — имя модели; повторы при 429/5xx агент делает сам |
| «остановлено лимитом расходов» | поднять `MISB_MAX_USD` или выбрать модель дешевле |
| источник `blocked` | сайт требует капчу или вход — так и должно быть, не обходится |
| статус «Не отвечает» на сайте | сбор оборвался; `progress/current` починится следующим запуском |

## Отличия от версии на Claude

- Вместо задания Claude (Routine) работают таймер systemd и `misb.agent`. Текст запуска собирается в `agent.py`
  (`launch_text`), инструкция — та же `collector/INSTRUCTIONS.md`.
- `routine/` и записи `config/collector` про задание Claude здесь не используются.
- Ссылка в итоговом сообщении сбора ведёт на свой сайт (`MISB_SITE_URL`).
- Сбор пишет в базу локально, без сети, поэтому быстрее. Модель через OpenRouter стоит денег за каждый токен — отсюда
  лимиты и сокращение истории.
