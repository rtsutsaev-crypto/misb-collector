# Energybase: закупки ТЭК по подготовке персонала

energybase.ru — отраслевой агрегатор закупок нефтегаза, энергетики и угля. Для МИСБ полезен раздел
«Подготовка персонала» (`/tender/catalog/training-services`) и тот же раздел на страницах крупных групп
(`/<отрасль>/<компания>/tenders/training-services`).

**Доступ (проверено 28.09.2026).** Страницы открываются из облака и через curl, и через WebFetch; карточки
лежат в HTML (`tender-card`): название, заказчик, сумма, даты объявления и окончания подачи заявок.
Регистрационный номер и площадка скрыты за входом. robots.txt запрещает адреса с `?` (значит, и `?page=N`),
`/search` и `/tender-outdated`, а для ClaudeBot просит 6 с между запросами — поэтому читается только первая
страница каждого адреса (20 карточек). В общем разделе это примерно 5 последних дней, в разделах групп —
несколько месяцев.

**В сборе.** Источник `energybase` в `config/sources-plan` (тип `pages`, 10 адресов: общий раздел и
Газпром нефть, Роснефть, Лукойл, Газпром, Татнефть, Транснефть, Росатом, РусГидро, СИБУР; пауза 6 с,
`drop_regions` Казахстан и Беларусь, заказчики «ТОО» отбрасываются). ID лида — идентификатор карточки из
ссылки `/tender/<id>` без приставки; тот же ID ставит импорт выгрузки «Монитора тендеров РФ», поэтому одна
карточка не попадает в базу дважды. Страницы Сургутнефтегаза (404) и НОВАТЭКа (переадресация) не работают.

**Первый проход** сделан из сеанса Claude скриптом `energybase_pages.py` (`fetch` — скачать страницы с
паузой, `parse` — разобрать и отобрать по словарю так же, как профили групп): 120 карточек, по темам МИСБ 44,
14 уже были в базе, 2 — Казахстан, новых 30 (7 с открытым приёмом) → `leadsets/run-20260928-1930-energybase`.

**Ещё 37 компаний (28.09.2026).** `companies.json` — список компаний каталога Energybase (ядро из 9 групп и
ещё 42 адреса); из них 37 страниц раздела «Подготовка персонала» открываются и отдают карточки. Они вынесены в
источник `energybase-cos` плана (тип `pages`, `batch` 8, пауза 6 с; курсор в `meta/rotation`). Первый проход:
195 карточек, не по теме 87, уже в базе 86, новых 22 (1 с открытым приёмом; остальные завершены — это сигнал
повторяющихся закупок компании) → `leadsets/run-20260928-2100-energybase-cos`.
