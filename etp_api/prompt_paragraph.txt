- etp-search (МТС Закупки, ЭТП РЭСТ, Торги РФ, Торги Федерации; без ключа): публичные JSON-списки этих сайтов, которые их страницы грузят без входа; из облака открываются, проверено 29.09.2026. Прочитай config/etpsearch (get) и сохрани поле code в etp_search.py; прочитай config/dictionary (get) и сохрани его как dictionary.json (целиком, поле data если оно есть; скрипт сам разбирает формы, темы и исключения). Известные id лидов из шага 2 запиши в known.txt, по одному в строке. Порция слов по кругу: начало — cursors.etp-search из meta/rotation (нет — 0), размер — поле batch источника. Запусти в фоне: nohup python3 etp_search.py --terms dictionary.json --topics --sources <поле sources источника> --pause <pause> --limit-words <batch> --offset <начало> --known known.txt --date <сегодня> --out out.json > etp.log 2>&1 & — и жди появления out.json (до 12 минут), обновляя progress раз в минуту (stage «Читаю ЭТП: поиск по словам»). В out.json: leads — готовые объекты лидов (поля как в шаге 4, source задан по площадке; их не менять, цены и сроки не придумывать), stats — счётчики по площадкам (requests, records, matched, new, errors), nextOffset, totalWords. Запиши leads в leadsets, doc_id = runId + "-etp-search" (шаг 5; не больше 300 лидов в документе). В progress: planned = done = batch, found = сумма stats.*.matched, fresh = число leads, note = «слова N–M из K; МТС X, РЭСТ Y, Торги РФ Z, Торги Федерации W новых»; status ok, если хотя бы у одной площадки requests больше числа errors, иначе failed с первой ошибкой из stats.<площадка>.errors. Ошибка этого источника сбор не останавливает. После источника обнови meta/rotation: cursors.etp-search = nextOffset (остальные ключи cursors не трогай).
