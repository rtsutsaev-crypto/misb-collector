# Глубина по ЕИС через ГосПлан и планы закупок

Скрипты для замеров и разовых загрузок; регулярный сбор идёт по плану `config/sources-plan` (запись `gosplan`
с полем `deep`, источники `gosplan-topics`, `gosplan-quotes`, `gosplan-plan44`, `gosplan-plan223`).

- `gp_deep.py explore W` — сколько лидов даёт каждый вариант запроса (вторая страница, ОКПД2 74.90 и 85.59, слова
  словаря по темам, малый объём по 44-ФЗ). Результат замера 29.09.2026: +451 лид по закупкам, +70 позиций планов
  44-ФЗ, +80 позиций планов 223-ФЗ; ОКПД2 85.59 через параметр `classifier` данных не отдаёт, 74.90 даёт мало.
- `gp_deep.py plans44 W --pages N`, `gp_deep.py plans223 W --newest N --since ДАТА` — планы закупок: позиции
  44-ФЗ с годом публикации позже текущего и позиции планов 223-ФЗ; лид `plan44-<номер позиции>` и
  `plan223-<план>-<номер>`, `flags: ["plan"]`.
- `plan_entries.py` — записи плана сбора для этих источников и для соседних рынков (`by-icetrade`,
  `by-goszakupki`, `uz-uzex`, `kg-zakupki`) и прямого спроса (`tenderguru-quotes`).

Ключ ГосПлана читается только из переменной окружения `GOSPLAN_KEY`; в репозитории ключей нет. Лимит ключа
10 запросов в секунду и 12 000 в час; пауза 2 с между запросами.
