# Чтение сайтов со списком, который строит скрипт

Часть площадок (Bidzaar, порталы Москвы и Узбекистана, ЭТП, корпоративные разделы) отдаёт пустую оболочку, а список закупок
рисует JavaScript. `WebFetch` и `curl` видят оболочку без строк, поэтому такие источники в реестре стоят как «открывается,
списка не видно». Скрипт открывает страницу настоящим браузером (Chromium уже есть в облачном образе Claude Code).

```
sh setup_trust.sh                                # один раз на контейнер: браузер доверяет CA прокси, проверка TLS остаётся включённой
PLAYWRIGHT_MODULE=/opt/node22/lib/node_modules/playwright \
  node render_list.cjs URL --out result.json [--scrolls 3] [--wait 6000]
```

Правила скрипта:
- сначала читает `robots.txt` сайта (правила группы `*`); запрещённый раздел не открывается;
- открывает страницу один раз, прокручивает несколько экранов, чтобы подгрузился список, читает отрисованный текст;
- страницу-заслон (капча, «проверка браузера», доступ запрещён) не обходит: результат `gate`, источник помечается как закрытый;
- не входит в аккаунты, не заполняет формы, не открывает то, что за регистрацией;
- проверку TLS не отключает (`setup_trust.sh` добавляет CA прокси в хранилище браузера, а не отключает проверку).

Результат: `status` (`ok` | `robots` | `gate` | `error`), `title`, `textLength`, `procWords`, `dates`, `rows[]` (текст строки и
ссылка), `jsonEndpoints[]` (публичные JSON-ответы, которые страница сама загрузила: адрес, размер, ключи первой записи).

Проверка 29.09.2026 на 16 адресах динамических площадок (браузер доверяет CA прокси, проверка TLS включена):
- 4 не ответили за 150 секунд (Air Astana, ERG, Казахтелеком, МТС), 5 отдали пустую страницу (Bidzaar, Фабрикант, ЕАТ, портал Москвы,
  Ростелеком) — похоже на защиту от headless-браузера, не обходится;
- ЭТП РАД: главная страница сама грузит публичный JSON `lots/query-extended` — открытых закупок 1 993, по словам МИСБ около 36
  (у части номер ЕИС, они уже приходят через ГосПлан); подключено как обычный `api`-источник `rad-lots`, браузер не нужен;
- Узбекистан (xarid.uzex.uz): API отвечает «Unknown User-Agent» не-браузерам; список конкурсов из браузера — 4 945 записей без
  названий, только категория (300 из первых 500 — подбор персонала), закупок обучения нет — источник не подключён;
- OnlineContract блокирует не-браузеры страницей «доступ запрещён» — не используется;
- остальные (ESTP, ПИК, Полюс, АЛРОСА, ЭТП РАД, Onlinecontract) без публичного списка без входа.
Вывод: чтение браузером даёт около 10–40 лидов (РАД), а не сотни.
