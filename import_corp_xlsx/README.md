# Импорт книги компаний и отраслей

`corp_xlsx_import.py` читает книгу «Корпоративные лиды МИСБ» (20 отраслевых сегментов) и разносит данные:
`orgdir/segments` (сегменты, темы, номер группы в подборке), подсказки `innHint`, `segment`, `groupHint` в
`orgdir/group-candidates`, новые адреса корпоративных сайтов. Лиды из книги в базу не загружаются: записи без
номера закупки и срока не считаются закупками. Ключей в скрипте нет.
